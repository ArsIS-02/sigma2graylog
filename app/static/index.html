Подключение к Graylog

Адрес, по которому приложение ходит в API.
Подставляется в ссылки «открыть в Graylog». Должен резолвиться с рабочих машин.
Секреты хранятся на сервере в зашифрованном виде (`/data/settings.json`, права 600) и в браузер не возвращаются. Пустое поле оставляет прежнее значение.

Создать Event Definition

Детект появится в Graylog и начнёт выполняться по расписанию.

Экстрактор для поля

Для auditd путь собирается как cwd + name: сначала каталог, потом имя файла.
Вставьте в Graylog: System → Pipelines → нужный pipeline → New rule, затем подключите правило к стриму.

Смена пароля

Пароль хранится как scrypt-хэш, смена сразу завершает другие сессии.
